# ESP32-C3 Wi-Fi 航模電調／舵機控制器

**用手機直接控制航模電調與舵機：免安裝 App、免路由器、免網際網路。**

[English](README.md) · [繁體中文](README.zh-TW.md)

</div>

ESP32-C3 Wi-Fi 航模控制器是一個開源的網頁控制工具，可用於控制 RC 電調（ESC）與舵機。ESP32 會自行建立 Wi-Fi 熱點並提供手機、平板或電腦瀏覽器可使用的控制介面。

不需要安裝專用手機 App。只要連上 ESP32 的 Wi-Fi，再開啟控制網頁即可。

## 功能特色

- **獨立 Wi-Fi 熱點**：不需要路由器或網際網路。
- **網頁控制介面**：可使用 Safari、Chrome 等現代瀏覽器。
- **電調油門控制**：可調整 0% 至 100%。
- **舵機角度控制**：可調整 0° 至 180°。
- **PWM 資訊顯示**：查看目前輸出脈衝寬度（微秒）。
- **快速操作**：最低油門、25% 快捷設定、增減微調及舵機回中。
- **逾時安全輸出**：控制指令停止送達時，電調輸出回到最低油門，舵機回到中位。
- **容易修改**：使用 Arduino 框架、ESP32Servo 與 ESP32 WebServer。

## 硬體需求

主要目標開發板：**ESP32-C3 Super Mini**。

另外需要航模電調與無刷馬達，或相容的舵機，以及符合設備規格的外部電源。首次燒錄需要 USB 資料線。

## 接線方式

預設訊號輸出腳位：**GPIO4**。

| ESP32-C3 | 電調／舵機 |
|---|---|
| GPIO4 | PWM 訊號線 |
| GND | 訊號地線 |
| 外部電源 | 依設備規格供應電調或舵機電源 |

ESP32 與電調的訊號地必須共地。不可將馬達直接接到 ESP32 GPIO，也不可將電調電池正極接到 GPIO。

## 安裝與開始使用

1. 安裝 Arduino IDE 與 ESP32 開發板套件。
2. 安裝 `ESP32Servo` 函式庫。
3. 開啟 `ESP32C3_WiFi_RC_Controller.ino`。
4. 選擇 `ESP32C3 Dev Module` 或符合你開發板的設定。
5. 編譯並燒錄韌體。

### 用手機連線

在手機的 Wi-Fi 設定中連接 ESP32 建立的網路：

| 設定 | 預設值 |
|---|---|
| Wi-Fi 名稱（SSID） | `ESP32-RC-Control` |
| 密碼 | `rccontrol` |
| 控制網頁 | `http://192.168.4.1` |

如果手機提示此 Wi-Fi 沒有網際網路，請選擇保持連線。

## 控制模式

### 電調（ESC）模式

- 油門：0–100%
- 預設脈衝範圍：1000–2000 µs
- 可快速回到最低油門或設定為 25%

| 電調油門 | 脈衝寬度 |
|---:|---:|
| 0% | 1000 µs |
| 25% | 1250 µs |
| 50% | 1500 µs |
| 75% | 1750 µs |
| 100% | 2000 µs |

這些百分比代表設定的控制脈衝範圍，不代表馬達實際轉速、扭力或推力。馬達反應不一定是線性的。請確認電調支援的訊號範圍與解鎖程序。

### 舵機模式

- 角度：0–180°
- 預設脈衝範圍：500–2500 µs
- 中位：90°

不同舵機可接受的脈衝範圍可能不同。如果舵機發出異音、過熱或碰到機械限位，請縮小脈衝範圍。

## 自訂設定

可在程式中修改以下項目：

- `SIGNAL_PIN`：PWM 輸出 GPIO
- `ESC_MIN_US` / `ESC_MAX_US`：電調脈衝上下限
- `SERVO_MIN_US` / `SERVO_MAX_US`：舵機脈衝上下限
- `FAILSAFE_MS`：控制逾時時間
- `AP_SSID` / `AP_PASSWORD`：Wi-Fi 名稱與密碼

## 安全注意事項

**測試前請務必拆除所有螺旋槳。**

- 啟動前先固定馬達與電調。
- 確認電調支援的輸入訊號與解鎖程序。
- 部分電調在使用前需要進行油門校準。
- 不可透過 ESP32 GPIO 直接為馬達供電。
- 本專案的逾時保護只是基本軟體機制，不是經認證的飛行控制安全系統。
- 請勿將本專案作為飛行器唯一的控制或失聯保護系統。

使用者需自行承擔使用風險。
